# Screenshots

Pictures of the window, taken by the application's own scripted tour without a display
(`FIN_BS_DEMO=<folder>` with the offscreen platform and the software renderer, see the Qt UX skill
under `.claude/skills/qt-ux/`). They show the BENELUX scenario of
[the research note](../research/benelux-option-candidates.md). Refresh them when the layout changes.
